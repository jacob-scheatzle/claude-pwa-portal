MCP OAuth clients

Pre-registered OAuth clients for connecting an MCP client (e.g. claude.ai) to this portal's /mcp server with explicit credentials. Most clients, including claude.ai, register themselves automatically — you only need this if a connector asks you to enter a Client ID and Client Secret.

Connecting still requires the one-time browser sign-in + approval (OAuth's authorization-code flow); a pre-registered client only skips automatic registration. The portal must be reachable over HTTPS for claude.ai to use it.
