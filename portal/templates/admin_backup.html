Backup

One-click downloadable archive of everything in the portal's data/ directory.

What's included

  • portal.db — users, apps, settings, API tokens, sessions, per-user app access. A consistent SQLite online-backup snapshot (safe to take while the portal is live).
  • apps/ — every uploaded child-app bundle, extracted.
  • storage/ — per-app, per-user key/value storage from portal.storage.* calls.

What's not included

  • The .env file (lives outside the container; holds SECRET_KEY).
  • Caddy's TLS cert cache (regenerated on demand on first hit per subdomain).
This archive contains secrets. The SMTP password inside portal.db is Fernet-encrypted with a key derived from SECRET_KEY; you need both this tarball and the original SECRET_KEY to restore SMTP. Store the file somewhere only you can read.

Restoring on a new host

  1. Stand up the portal stack on the new host with the same SECRET_KEY as the source — otherwise the encrypted SMTP password row won't decrypt.
  2. Stop the containers: docker compose down
  3. Extract the archive into the empty data directory, preserving permissions: 
    sudo rm -rf data/*
sudo tar -xzf pwa-portal-backup-*.tar.gz -C data/
sudo chown -R 1001:1001 data/
  4. Start the stack: docker compose up -d
